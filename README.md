# Arabic in Riyadh

Русскоязычный учебный MVP разговорного саудовского арабского: Next.js, React, TypeScript и Tailwind CSS. Регистрация и API-ключи не нужны.

## Локальный запуск

Node.js 22+ (проверено на 24), npm.

```sh
npm ci
npm run dev
```

Приложение доступно на порту 3000. Production: `npm run build && npm start`.
Проверки: `npm run typecheck`, `npm test`. Браузерные проверки: `npx playwright test` (нужен Chromium; конфигурация использует `/usr/bin/chromium`).

## Структура

- `app/` — страница, метаданные, адаптивные стили.
- `components/LearningApp.tsx` — dashboard, LessonCard, VocabularyCard, AudioPlayer, DialoguePlayer, AlphabetTrainer, QuizEngine, ReviewTrainer, GrammarExplanation, ConversationTrainer.
- `lib/course.ts` — 12 уроков A0/A1, 28 букв, словарь, 15 грамматических моделей, 14 диалогов, сравнения с фусхой.
- `lib/progress.ts` — абстракция localStorage, нормализация ответов и интервальное повторение.
- `tests/` — проверки данных, алгоритма и пользовательских сценариев.

## Редактирование материалов

Добавляйте слова в `words` через исходный массив `raw` в `lib/course.ts`; lesson.indices содержит индексы этих слов. Добавляйте урок в `specs` с названием, целями, диапазоном слов, объяснением, моделью и типичной ошибкой. Новый материал должен иметь непустые примеры и практику. Диалоги хранятся отдельно с ролью, арабской репликой, транслитерацией и переводом.

Стиль: нейтральная саудовская речь с ориентацией на городской Эр-Рияд. أبي — надждийский вариант, أبغى — широко понятная альтернатива. Не добавляйте египетские/левантийские формы без пометки. ā ī ū — долгие гласные; ʿ — ع, ḥ — ح, kh — خ, gh — غ, ṣ ḍ ṭ ẓ — эмфатические; q — формальное ق, g — распространённое надждийское произношение в соответствующих словах. Русская передача названий букв приблизительна.

Все материалы имеют `verification: needs-native-review`: проверка носителем ещё не выполнена, ссылки и экспертная проверка не выдуманы. Перед публичным образовательным релизом нужна редактура носителем из Эр-Рияда, особенно транслитерации и региональных вариантов. Грамматическая практика начальная, не полноценная сертификация A1. Каждый урок использует тематическую модель для пропусков и составления фраз; некоторые базовые задания на буквы и порядок беседы повторяются для закрепления.

## Аудио носителей

Добавьте лицензированный файл в `public/audio/`, затем `word.audio = { url: '/audio/file.mp3', verified: true, license: 'лицензия / автор / согласие' }`. Ставьте `verified` только после проверки носителем; такие записи имеют приоритет. Такие же метаданные поддерживаются в `word.exampleAudio`, `dialogue.lines[i].audio` и `dialogue.audio` для целого диалога; AudioPlayer автоматически отдаёт проверенным записям приоритет.

По умолчанию используется Web Speech API: сначала ar-SA, затем другой арабский голос. Даже ar-SA **не считается аутентичным надждийским аудио**. При отсутствии голоса отображается объяснение. Установите арабский голос в системе. Запись микрофона требует HTTPS или localhost и разрешения; поддержка MediaRecorder проверяется. Записи не отправляются на сервер и удаляются при закрытии вкладки. Оценка акцента и распознавание речи не имитируются.

## Прогресс

Ключ `riyadh-progress-v1`. Урок завершается при результате 4/5 или лучше; его слова попадают в повторение, а существующие интервалы сохраняются. Избранное, ошибки, завершения и интервалы сохраняются между сессиями. Скачивание JSON доступно в настройках. Интервалы: не знаю — 10 минут, сложно — 1 день, помню — ×2 (минимум 2 дня), легко — ×3 (минимум 4 дня). Время берётся с устройства. Счётчик дней означает дни с практикой, не непрерывную серию. При запрете storage показана ошибка; синхронизации между устройствами нет.

## Развёртывание и расширение

Разверните на Vercel или Node-хостинге с `npm ci && npm run build`, затем `npm start`; HTTPS обязателен для микрофона на удалённом устройстве. Шрифты поставляются локально из @fontsource, сторонний CDN в работе не нужен.

- Авторизация: добавить серверные сессии и провайдера auth; сохранить гостевой режим и предложить перенос локального прогресса.
- Синхронизация: заменить адаптер storage на API с валидацией, версиями и разрешением конфликтов.
- AI tutor: отдельный server route, ключ только на сервере, проверка запросов и лимиты. ConversationTrainer сейчас исключительно сценарный; представить API-адаптер с тем же состоянием диалога.
- Подписки: серверные checkout/webhooks и проверка прав; не хранить платёжные секреты в браузере.
- A2, профессиональная озвучка, полная редактура носителем — будущие расширения.

## Ограничения

Приложение не обещает свободную речь или точную оценку произношения. Голоса и поведение Safari зависят от устройства. Автоматические WebKit-проверки не заменяют проверку на физическом iPhone. Перевод/транслитерация переключаются в настройках; огласовки убираются только там, где они есть в данных. В курсе большинство разговорных слов записано без огласовок.

### Проверка Safari / WebKit

Chromium-проверки запускаются без загрузки браузера. Для WebKit:

```sh
PLAYWRIGHT_BROWSERS_PATH=/workspace/.playwright npx playwright install webkit
PLAYWRIGHT_BROWSERS_PATH=/workspace/.playwright npx playwright test --config playwright.webkit.config.ts
```

В текущем окружении загрузка WebKit заблокирована сетевой политикой (HTTP 403 Domain forbidden). В черновик настроек добавлены `cdn.playwright.dev` и `playwright.download.prss.microsoft.com`; изменения требуют сохранения пользователем в настройках окружения. WebKit и физический iPhone не проверены. Конфигурация WebKit выбирает мобильный сценарий и эмулирует iPhone; это не проверка на физическом устройстве.
